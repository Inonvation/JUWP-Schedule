## 5. 非功能

| 项 | 要求 |
|----|------|
| 隐私 | 账号/Token 不进 Log；不上传第三方分析；笔记·课件与作业（含图片）只存本机私有目录，无任何网络出口（§4.20）；课表背景图同样只落 `filesDir/schedule_bg/`（§4.21）。唯一的对外坐标出口是附近单车地图（§4.23）：只发地图中心坐标 + `deviceType`，不含账号或设备标识。默认中心是硬编码的校园坐标；只有用户点「定位」才会把个人位置发出去 |
| 权限 | 网络 + 可选 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`（小组件后台及时性，见 §3.6）+ `ACCESS_FINE/COARSE_LOCATION`（附近单车地图的「定位」，只在点按钮时申请，见 §4.23）；`VIBRATE`（免费时长提醒的震动，普通权限、安装即授予，见 §3.9）；笔记/作业与课表背景的选图走系统 Photo Picker，不申请相册权限（§4.20/§4.21） |
| 性能 | 首页可交互 < 2s（中端机冷启动参考）；公式按 (源码, 字号) 内存缓存，图片按下采样尺寸解码（§4.20） |
| 体积 | APK 目标 < 15MB。**2026-09-21 起 release 开启 R8 + 资源压缩**（此前 `isMinifyEnabled=false`，1.0.0 实测 17.9MB 超标）；开启后 release 实测 **3.6MB**。改混淆规则后必须装 release 包冒烟——R8 的问题只在运行时暴露 |
| 稳定 | 胖乖接口失败不崩溃；教务 WebView 与原生状态分离 |
| 合规 | README/设置含免责；不内置破解/刷分 |

> **2026-09-24（§4.27）**：上表「隐私」行的口径将扩充——教务统一认证密码
> 加密存本机（`jw_credentials.xml`，复用既有备份排除规则），仅用于会话失效后的
> 静默续登；用户可在「我的」页状态卡随时退出并清除。

## 7. 风险

1. **教务未知**：无 URL 则 P5 阻塞；用手动课表兜底。  
2. **胖乖接口变更**：light-life 已提示接口可能再变；网络层集中改 Base/路径。  
3. **包名/品牌侵权观感**：名称用「水贝贝」等非官方注册滥用词；README 注明非学校官方。  
4. **路线 D 工期**：比 fork 长；M1 严格砍范围，先能上课、能开水。  
5. **实验课表 DOM 未知**：必须先做 §4.8 Step 0 快照，否则解析器只能靠猜；syjx 页面若为 AJAX 渲染，注入时机需实测。  
6. **教务链路易被代理出口破坏**：shell 注入的 `HTTP_PROXY`/`HTTPS_PROXY` 与用户手机上的 VPN/代理，
   都会让 CAS/SSO 落点 404/500 或超时——同一 URL 时好时坏，**不是教务不稳定**。脚本侧 Session
   一律 `trust_env = false`；App 侧 `JwVpnDetector` 检测 + `data/session/NetworkHint.kt` 统一文案
   （开着代理点名关、没开就换一条网络；密码错、平台结构变化等与出口无关的失败不给这条提示）。
   见 §4.4.1。

7. **自动续登依赖 CAS 的三件未知**（§4.27）：① 同账号并发会话是否互踢（决定后台登录会不会
   顶掉用户浏览器的会话）；② TGC 实际寿命（决定重登频率与「存密码」是否划算）；
   ③ 触发验证码时的页面特征（无样本，验不通就按「未知 200 一律转 WebView」兜底）。
   验证办法：`scripts/jw_session.py` 改造成探针即可，不必先装 App。无论结论如何，
   「失败 2 次即停用」的闸门不能松——自动重登不能把「手动输错」变成「App 反复撞」。

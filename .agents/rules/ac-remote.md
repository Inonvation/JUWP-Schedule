# 宿舍空调遥控（生活页 · 校园服务）

作用域：改 `domain/MideaAc`、`ui/life/AcRemote*`、`data/ir/`、`data/prefs/AcRemotePrefsStore`、
生活页「校园服务」那张卡与主界面接线时读。规格见 DESIGN §3.31 / §4.48。

## 协议口径（改帧 / 波形前必读）

- 48 位协议：帧 6 字节 = `0xA1` 头 / 电源·睡眠·风速·模式位 / 温度位 / 关机定时字节 /
  开机定时字节 / 校验和。校验和 = 前 5 字节逐字节按位反序求和 → 取 256 的补 → 再按位反序。
- 温度 17–30 在 `MideaAc.frame` 钳制；睡眠 = 第二字节位 6；定时见 `timerByte`
  （30 分钟一档、0.5–24 小时、不足 30 分钟或 null = 0xFF 不定时；档位 N 时
  `0x80 | ((N-1) shl 1) | 1`；7 小时 = 0x9B，对齐上游 raw `A1A34DFF9B34`）。
- 切换类功能（摆风 / 屏显 / 强力 / ECO）协议里没有状态位：特殊帧 `MideaAc.Toggle`
  （`0xA2` 头）与主帧**连发**（先主帧、后切换帧）；界面记忆在 `MideaAc.Toggles`
  （跟快照落盘），物理遥控动过会不同步，接受。
- 波形 = 头 4480/4480 → 正码 48 位 → 560/5600 → 头 → 按位取反 48 位 → 560/105600；
  默认连发 2 组（一组约 260ms）。
- **动任何一位之前先动 `MideaAcTest` 的上游向量**：校验和 5 组、完整波形 2 组、重复组
  边界、定时 7 小时、切换帧校验和都是 IRremoteESP8266 `ir_Midea` 的核验值（2026-10-16），
  别只改实现不改测试。
- 模式 / 风速持久化存**协议位值**（不是 ordinal）。

## 纪律

- 发射只走 `AcIrBlaster`（ConsumerIrManager 是平台唯一出口）；`TRANSMIT_IR` 是普通权限，
  不弹窗、不申请。
- 发射在 `AcRemoteViewModel` 里走 `sendLock`（Mutex）**串行化**：连点与温度长按连发的
  帧序靠它，别把 `transmit` 挪出互斥。
- 温度长按连发的起判 / 间隔（`HOLD_START_DELAY_MS` / `HOLD_REPEAT_INTERVAL_MS`，
  `AcRemoteScreen` 页内常量）改前先真机对拍；松手时点击回调补一步是**有意的**
  （原装遥控手感，数值看得到）。送风档温度置灰（`state.mode != Fan`）只在 UI 层拦。
- 页面走描边卡分组（主控 / 模式风速 / 附加 / 定时）；定时两行是卡内平铺行口径
  （`AppCardDivider` 分隔、行自己 clickable + haptics）。
- **每次操作发完整状态帧**，同时写回 `AcRemotePrefsStore`；空调无回执，面板显示的是
  「本机替它记的设定」，别在 UI 上做「查询空调状态」这类不存在的动作。
- 无红外发射器机型：进页只给提示（`AcIrBlaster.supported`），不发空炮、不做隐藏入口。
- 入口固定在生活页「校园服务」卡、**成绩查询前**（2026-10-16 用户拍板），别挪去百宝箱。
- 真机点验口径：对着空调按电源，开机 / 关机两态各响应即过。不通时先换协议变体
  （Coolix / Midea24）在这条链上试，别直接改 UI。

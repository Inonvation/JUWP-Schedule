# 宿舍空调遥控（今日页 · 江水生活）

作用域：改 `domain/MideaR05d`、`ui/life/AcRemote*`、`data/ir/`、`data/prefs/AcRemotePrefsStore`、
今日页「江水生活」的图标入口与主界面接线时读。规格见 DESIGN §3.31 / §4.48。

## 协议口径（改帧 / 波形前必读）

**只走 R05D**（国内美的挂机；2026-10-18 起默认，2026-10-20 移除 A1 整套口径）：

- 6 字节 = 固定头 `B2 4D` + 功能字节 B + `~B` + 模式/温度字节 C + `~C`，
  整帧原样连发两遍，没有额外校验和。关机是专用帧 `B2 4D 7B 84 E0 1F`
  （B=0x7B、C=0xE0），不是翻电源位。温度 / 模式 / 风速查 `MideaR05d` 的表
  （温度非二进制顺序；送风取 0xEF 的「无定义」档）。波形 = 头 4400/4400 →
  48 位 → 550/5220 → 头 → 48 位 → 550/8800，一组约 192ms。
- **扩展键（2026-10-20 加，真机未验证）**：
  - 摆风：`B2 4D 6B 94 E0 1F`，固定帧发两遍；
  - 强劲：`B5 4A F5 0A A2 5D`（A=0xB5），固定帧发两遍，再按一次关闭；
  - ECO：先发 `B2 4D E0 1F 03 FC`，再发当前状态帧两遍；取消 = 只发状态帧两遍
    （所以任意普通按键都会取消，`updateState` 顺手清 `ecoOn`）。三帧约 286ms，
    仍在 400ms 预算内。
  - 睡眠 / 屏显没有公开编码，不做；定时（C/D 字节）未做。
  - 依据：第三方《R05d 电控功能说明书》与早期抓码；**没在真机逐键验证过**。
    加 / 改之前先补 `MideaR05dTest` 的帧期望，再让用户对着空调逐个按。
- 发一次按键默认只发 1 次（一次 `transmit` = 一组 = 空调一声蜂鸣；
  2026-10-20 由补发 2 次改为 1 次）。长按电源连发 4 次。
- **动任何一位之前先动测试**：R05D 的实测向量 `B2 4D BF 40 D0 2F`（自动风 26℃ 制冷）/
  `B2 4D 7B 84 E0 1F`（关机）、三个扩展帧、ECO 三帧序列与预算都在 `MideaR05dTest`。
  别只改实现不改测试。
- 模式 / 风速持久化存**枚举名**（`AcRemotePrefsStore`）；A1 时代的 `mode_bits` /
  `fan_bits` 在读取时按旧位值迁移一次，保存时清掉遗留键。

## 纪律

- 发射只走 `AcIrBlaster`（ConsumerIrManager 是平台唯一出口）；`TRANSMIT_IR` 是普通权限，
  不弹窗、不申请。
- 发射在 `AcRemoteViewModel` 里走 `sendLock`（Mutex）**串行化**：连点与温度长按连发的
  帧序靠它，别把 `transmit` 挪出互斥。
- 温度长按连发的起判 / 间隔（`HOLD_START_DELAY_MS` / `HOLD_REPEAT_INTERVAL_MS`，
  `AcRemoteScreen` 页内常量）改前先真机对拍；松手时点击回调补一步是**有意的**
  （原装遥控手感，数值看得到）。送风档温度置灰（`state.mode != Fan`）只在 UI 层拦。
- 页面走描边卡分组（主控 / 模式风速 / 附加）；定时 / 睡眠卡已随 A1 一起删除，别加回来。
- **每次操作发完整状态帧**，同时写回 `AcRemotePrefsStore`；空调无回执，面板显示的是
  「本机替它记的设定」，别在 UI 上做「查询空调状态」这类不存在的动作。
- 扩展键（摆风 / 强劲 / ECO）没有状态位，芯片只是本机记忆；关机时禁用（原装遥控的
  摆风 / 强劲键在关机时不响应，ECO 关机发会拼出关机帧）。
- 无红外发射器机型：进页只给提示（`AcIrBlaster.supported`），不发空炮、不做隐藏入口。
- 入口 2026-10-16 在生活页「校园服务」卡（成绩查询前）；**2026-10-19 起迁到今日页
  「江水生活」的三枚图标入口之一**（取快递 / U净 / 空调遥控）。别再挪去百宝箱，也别加回生活页。
- 真机点验口径：对着空调按电源，开机 / 关机两态各响应即过；再逐个点摆风 / 强劲 / ECO，
  确认空调有蜂鸣与动作。不通时先查是否对准接收窗、距离，再考虑抓码，不要改 UI 绕。

## 功能

**课表**

- 一键从教务系统导入学期课表：自动依次读取**理论课表**与**实验课表**，导入前先给出识别结果
- 两张课表**合并进同一张课表**（按课程名+星期+节次+类型去重），**考试安排**同样可一键导入
- 导入确认弹窗里可切换学期，换一个学期就重新抓取一次
- 导入完成后自动抓取本学期**教材**，在课程详情里查看（教材页只读，不会替你提交确认）
- 导入结果以页面下方提示条反馈：导了几门、覆盖还是合并、导到哪张表
- 上课提醒、系统日历同步、调课规划
- 课表页可换自定义背景图

**成绩**

- 一键导入全部学期成绩，按学期 / 学年分组，自动计算加权平均分与平均绩点
- 首次登录教务成功后、以及之后每次冷启动自动补一次（7 天内不重复请求，失败保留旧数据）

**笔记与作业**

- 笔记·课件：按课程归类，Markdown 正文 + TeX 公式，可插入图片
- 作业清单：按课程分组，记录截止日期与完成状态
- 作业截止提醒：截止前一天 20:00 与当天 20:00 各提醒一次未完成的作业

**学业完成情况**

- 抓取教务「学业达成情况」，按课程体系 / 课程性质 / 课程属性 / 公选课类别四个维度展示培养方案达成度（要求 / 已修 / 在修 / 还需学分）与课程明细
- 与成绩一起自动导入，同样 7 天闸门

**桌面小组件**

- 课表 / 校园卡 · 电费两条目：点课表条目进 App；生活卡主区是校园卡余额（点一下出全屏付款码），
  副行是寝室电费（点那一行进用电统计）
- 胖乖开水 / 趣智开水两枚固定 2×2 卡：主区是余额，胶囊进对应页面并**自动开始开水 / 开阀**；
  用水中时整卡切成已用分钟数
- 校园卡余额可在设置里隐藏；小组件自身不联网取数，读数跟随 App 内的更新

**外观**

- 内置六套主题配色：水电青（默认）· 晴空蓝 · 暮山紫 · 樱花粉 · 落日橙 · 森野绿
- 支持 Material You 动态取色（跟随壁纸），深色模式全页适配，底栏可切悬浮半透明

**扩展功能**

- 学工表单：**宿舍报修**与**请假**打开即到表单，填写、照片/附件上传、提交与进度查询都在 App 内完成；
  走学校统一身份认证，与教务同一套账号，登录过教务导入的话通常免登
- 生活页（底栏「生活」）：一卡通余额、付款码、**寝室剩余电量**、充值入口与最近流水收在一页，
  付款码默认不预取（点一下才显示）；电费充值可选**电子账户**与**农行支付**（App 内嵌手机版
  收银台，卡号与验证码只在银行页面里输入），每个充值入口先过一遍充值风险提醒；
  可在「我的 → 通用设置 → 页面与导航」关掉这一页
- 胖乖生活：一键开水、余额查询、订单记录
- 趣智校园：**开热水**——登录、余额与充值、账单、扫描并绑定附近热水器；开阀与结束用水结算
  都在 App 内完成，照常从趣智校园账户扣费。用水中状态记在本机（1 小时未结算按过期处理），
  今日页卡片与桌面小组件跟着显示「用水中」。协议来自公开逆向资料，非官方功能
- 快趣出行：**两种用车方式**——微信小程序（输入车号生成乘车码、一键拉起微信扫一扫，扫过的码
  在骑行结束后自动从相册删除）与**快趣账号登录**（App 内直接开锁、临时锁车与还车，含当前用车
  卡：电量、已骑时长与当前费用）。两档共用**内置地图**：看附近车辆、还车点与禁停区图层、
  点车自动填车号、按车号定位；扫码后自动开始**免费时长倒计时**（15 分钟，可用微信通知校准）
- 校园卡付款码：一键出示，喝水吃饭、寝室门禁不再需要水宝宝！支持查看一卡通余额与历史账单，
  消费流水标注充值到账的账户；凭证加密存本机，开启时会真实验证一次，可随时关闭并清除
- 取快递快捷方式：一键直达拼多多取件码、淘宝身份码与菜鸟（无广告启动），排队取快递不再匆忙
- 盖章成绩单：从教务签章系统导出带学校电子章的 PDF 成绩单，存本机，可在「最近导出」里重看或分享

**导入与备份**

- 课表、学期配置、作息、成绩与学业完成情况支持 JSON 备份，可随时导出与导入；笔记与作业不在该份备份里

## 使用

课表默认为空、不预置样例。「我的」页结构：顶部四枚服务格（教务 / 一卡通 / 胖乖生活 / 趣智校园）+ 设置节（通用设置 / 课表 / 学习 / 提醒与桌面 / 校园服务 / 关于）。

- 课表：**我的 → 课表 → 从教务导入**，或 **我的 → 教务 → 导入课表**，登录教务导入学期课表
- 成绩：**我的 → 学习 → 成绩查询**页内导入，或 **我的 → 教务 → 导入成绩**
- 学业完成情况：**我的 → 学习 → 学业完成情况**（登录教务成功后自动抓一次，7 天内不重复）
- 笔记与作业：**我的 → 学习**；也可在课表页或今日页点某节课，直接进这门课的笔记与作业
- 考试：在教务导入 WebView 内打开考试安排页，一键导入
- 盖章成绩单：**我的 → 教务 → 导出盖章成绩单**；成绩页也有入口
- 桌面小组件：**我的 → 提醒与桌面 → 桌面小组件**，支持在应用内一键添加到桌面
- 主题配色：**我的 → 通用设置 → 主题配色**（六套内置配色，动态取色默认开）
- 生活页开关：**我的 → 通用设置 → 页面与导航 → 生活页**
- 快趣出行：**我的 → 校园服务 → 第三方账号 → 快趣出行**；账号与本机骑行记录在「快趣账号」（仅账号登录方式显示）
- 免责声明：首启引导第一步有入口，之后在 **我的 → 关于 → 免责声明**；弹窗条文与本文一致，另有一条只在 App 内展示的「完全免费 · 认准官方下载源」；充值风险提醒在 **我的 → 关于 → 充值风险提醒**，每个充值入口也会先弹一次
- 开源许可：**我的 → 关于 → 开源许可**，列出随包分发的主要第三方组件与各自许可
- 趣智校园：**今日页底部「江水生活」里的右侧半行卡**（与胖乖生活并排，可在页内关闭卡片）；关掉后从 **我的 → 校园服务 → 第三方账号 → 趣智校园** 进入

## 构建与测试

```bash
./gradlew.bat :app:testDebugUnitTest :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk

./gradlew.bat :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk（R8 压缩 + 签名）
```

单测结果汇总在 `app/build/test-results/testDebugUnitTest/`。

本机依赖齐备后可加 `--offline`，构建快一个量级。改过混淆规则要装 release 包冒烟。
